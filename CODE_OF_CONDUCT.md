# Code of Conduct

Macro Deck is an open-source project. Participation should remain constructive, technical, and respectful.

## Expected behaviour

Contributors and community members are expected to:

- treat other people with respect, including when disagreeing
- keep discussions relevant and constructive
- give technical feedback about work rather than attacking the person behind it
- respect privacy and avoid publishing another person's private information without permission
- accept moderation decisions and requests to stop disruptive behaviour

## Unacceptable behaviour

The following is not acceptable in project spaces:

- harassment, threats, intimidation, or targeted abuse
- discriminatory or demeaning comments
- sexualized language, imagery, or unwanted sexual attention
- deliberate disruption, trolling, spam, or sustained off-topic behaviour
- publishing private information without permission
- encouraging others to engage in unacceptable behaviour

## Scope

This code applies to official Macro Deck project spaces, including repositories, issue and pull request discussions, documentation contributions, and community spaces operated by the project.

## Enforcement

Project maintainers may edit, remove, or reject contributions and comments that violate this code. Depending on severity or repeated behaviour, maintainers may issue a warning, temporarily restrict participation, or permanently ban a participant from project spaces.

Serious conduct concerns should be reported privately to the maintainers rather than discussed publicly. When a report concerns a security vulnerability, follow [SECURITY.md](SECURITY.md) instead.

Maintainers should handle reports as confidentially and consistently as practical and should avoid conflicts of interest when deciding enforcement actions.
