### Sign in to the web client

The web client asks for a **Pairing code** first. In Macro Deck on the computer, open the network panel with
the Wi-Fi icon at the top right and type the six digits shown under **Pairing code**; the web client signs in
as soon as the sixth digit is in. A pairing code works once and is valid for 15 minutes. If the web client
says the code is wrong or has expired, check the code in the panel: it changes after it is used, after it
expires, after several wrong tries and every time the panel is opened.

To use your Macro Deck account instead, choose **Password** above the field and enter your username and
password. After several wrong tries, Macro Deck makes you wait a moment before the next one.
